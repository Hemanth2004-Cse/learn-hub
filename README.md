📚 Learn Hub
🚀 About the Project
Learn Hub is an online learning platform designed to provide students with structured educational resources, project materials, documentation, and demo videos in one place.
The platform aims to simplify learning by organizing content in a clear and accessible manner for users.
🎯 Features
👤 User Features
* Access learning materials
* View project documentation
* Watch demo videos
* Easy navigation through structured content
🛠️ Admin Features
* Upload project files
* Manage documentation
* Update learning resources
* Maintain structured content
